One more step

Install and start the macOS helper app.

This Firefox add-on needs the companion macOS helper. The add-on finds the video; the helper creates the always-on-top PiP window.

1

Firefox add-on

You already have the browser part installed. It adds the toolbar button and sends the selected video locally.

2

macOS helper

Download the helper for your Mac, move it to Applications, then right-click it and choose Open.

Download helper

Apple Silicon Mac Intel Mac

This beta helper is free and not Apple-notarized yet. If macOS warns on first launch, right-click the app and choose Open.

After installing

  1. Start macOS External PiP Helper.app.
  2. Return to Firefox and refresh the video page.
  3. Start video playback.
  4. Click the macOS External PiP toolbar button again.
